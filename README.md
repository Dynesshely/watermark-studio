# 水印工坊（Watermark Studio）

纯浏览器端图片水印工具：**图片只在你的浏览器本地处理，不上传任何服务器**。

## 功能

- **导入**：文件选择（多选）/ 拖拽到页面 / 剪贴板粘贴（`Ctrl+V` 或列表底部「粘贴」按钮手动读取）。
  待命界面与编辑界面均可入口：编辑时用左侧列表**底部固定操作条**（新建图片 / 打开 / 粘贴，视觉一体、实为三按钮）
- **从颜色开始**：待命界面按钮或编辑界面列表底部「新建图片」→ 取色器 + 分辨率输入（含常用尺寸、宽高交换），
  支持**完全透明**底图（alpha=0 的 PNG，便于之后叠加到其它图片上）；生成后即进入正常编辑流程
- **水印类型**：平铺重复 与 单个水印 两种模式
- **文字**：支持多行（回车换行）、行距、系统字体选择、字重、描边、阴影、颜色、透明度
- **字号基准**：`按宽度 %`（批量图片视觉比例一致）或 `固定像素`，间距/偏移随之联动
- **角度**：-180°~180° 连续调节 + 常用角度快捷按钮
- **平铺专属**：横向/纵向间距分开调节、网格整体偏移（避开画面主体）
- **单次专属**：九宫格定位 + 位置滑杆，或在预览图上**直接拖拽水印**（松手靠近锚点自动吸附）
- **预览**：全分辨率实时渲染、缩放/平移（滚轮缩放：`Ctrl/⌘ + 滚轮`）、原图/效果切换
- **批量管理**：单击选中、单张移除、清空、拖拽排序、卡片上原图/效果缩略图切换
- **水印预设**（参数面板顶部）：把当前参数命名保存，随时**套用**；双击名称可重命名，
  支持用当前参数覆盖、**复制一份**、**导出单个 `.json`**、**全部打包为 `.zip`**（内含逐个 `.json`）、以及从 `.json` 导入；
预设多于 5 条时列表顶部出现搜索框（按名称或水印文字过滤）。
  导出文件自描述（`type` / `version` / `app.version` / `watermark`），导入时对字段做类型与范围钳制
- **导出**：与原图同格式（JPG/PNG/WebP；BMP、AVIF 与不支持 WebP 编码的浏览器回退为 PNG）、JPEG/WebP 质量可调、
  逐张下载 / 全部逐张下载 / **ZIP 打包**（含进度条）、文件名可配置模板（`{name}` 原名 / `{ext}` 扩展名，默认 `{name}_wm.{ext}`）
- **界面语言**：中文 / English，顶栏一键切换；首次访问按浏览器语言自动检测，选择随设置持久化
- **细节**：自动应用 EXIF 方向、超大图内存提示、导出时提示 EXIF 元数据将被清除、参数 localStorage 自动记忆（含深浅主题）

## 技术

- React 18 + TypeScript + Vite + Tailwind CSS v4（无组件库，手写控件）
- 国际化：零依赖手写 i18n（`src/i18n/zh.ts` 为基准字典，`en.ts` 的类型受其约束——漏译/多译会在 `tsc` 阶段报错）；
  语言存于设置中，切换时同步 `<html lang>`、页面标题与描述
- Canvas 2D 本地渲染，导出 Blob 走浏览器下载；ZIP 用 [jszip](https://github.com/Stuk/jszip)
- 移动端窄屏：图片列表变横向条、参数面板变抽屉

## 开发

```bash
pnpm install
pnpm dev        # http://<本机IP>:50011（同时监听 0.0.0.0，局域网设备可直接访问）
```

自定义域名访问：`http://watermark-studio.dev-u26-001.services.local:50011`
Vite 会校验 Host 头，新增域名须列入 `vite.config.ts` 顶部的 `ALLOWED_HOSTS`（`server` 与 `preview` 共用），否则返回 403。

## 构建

```bash
pnpm build      # tsc 类型检查 + vite 产物输出到 dist/
pnpm preview    # 本地预览生产构建
```

## 目录结构

```
src/
├── App.tsx                 # 应用装配：导入/解码/导出编排、三栏布局
├── components/
│   ├── ui.tsx              # 图标、按钮、滑块、取色、开关等控件 + Toast
│   ├── TopBar.tsx          # 顶栏（导入入口、主题）
│   ├── Hero.tsx            # 空状态引导页
│   ├── ImageList.tsx       # 批量列表（排序/移除/结果缩略图）
│   ├── PreviewPane.tsx     # 全分辨率画布预览（缩放平移/水印拖拽）
│   ├── SettingsPanel.tsx   # 水印参数面板
│   └── ExportPanel.tsx     # 导出下载面板（质量/模板/进度）
├── store/settings.tsx      # 参数状态 + localStorage 持久化
└── lib/
    ├── types.ts            # 参数模型与默认值
    ├── renderer.ts         # 水印绘制引擎（平铺网格/单次定位/旋转/描边阴影）
    ├── imaging.ts          # 解码（EXIF 方向）、格式嗅探、缩略图缓存
    ├── exporter.ts         # 批量处理流水线与 ZIP 打包
    ├── filename.ts         # 命名模板与去重
    └── fonts.ts / storage.ts
```

## 已知边界

- 浏览器安全限制：重编码导出会丢弃 EXIF 等元数据（界面会提示）
- GIF 动图 / HEIC / SVG 不支持（导入时会提示）
- 超大图全分辨率处理占用内存较高，导入后会有提示；建议单边不超过 8000px
